# База данных

PostgreSQL 17, драйвер pgx v5, миграции через golang-migrate.

## Структура

```text
db/migrations/                          миграции
db/seed/                                тестовые данные
db/normalized/                          нормализация и ER-диаграммы
internal/pkg/*/repo/postgres/queries/   SQL-запросы
```

## Миграции

Применяются сервисом `migrate` при запуске:

```bash
docker compose up -d postgres migrate s3
```

Тестовые пользователи `ada`, `grace`, `linus` с паролем `password`:

```bash
docker exec -i bnn-postgres psql -U bnn -d bnn < db/seed/users.sql
```

## Транзакции

- регистрация, refresh и смена пароля меняют пользователя и сессии вместе;
- создание заметки создаёт заметку, участника-автора и чат;
- сохранение заметки обновляет заметку, блоки, их версии и порядок;
- удаление заметки удаляет вложенные заметки и неиспользуемые блоки;
- загрузка вложения создаёт вложение и связь с блоком.

Чтение заметки с блоками — REPEATABLE READ, остальное — READ COMMITTED.

## Версия заметки

`GET /notes/{id}` возвращает `version`, `PUT /notes/{id}` присылает её обратно.
Если заметку уже изменили, вернётся 409.
